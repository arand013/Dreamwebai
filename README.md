# DreamWeb AI

AI & Creative Solutions for growing businesses — a New Gen LLC venture.

**What it is:** a local-business growth agency. Web presence, visibility
(local SEO / reviews / ads), metrics dashboards, and growth tech
(booking, CRM, automation) for businesses that want more customers
without becoming marketers.

**Live site:** https://arand013.github.io/DreamWeb-AI/

## Structure

- `index.html` — the live landing page (single file, no build step)
- Business docs live in Alex's Google Drive ("Business - DreamWeb AI" folder):
  pitch, call list, services, business plan — to be ingested once the
  Google Docs connector is linked.

## Deploy

Any push to `main` updates the live site via GitHub Pages.
